# Poker Advisor Pro — UX 优化设计文档

**日期**：2026-04-23  
**目标用户**：新手玩家  
**使用场景**：实际打牌时的实时辅助  
**核心痛点**：输入流程慢、建议面板难以理解  
**方案**：双管齐下（快速输入 + 建议可读性同步优化）

---

## 一、整体布局调整

### 问题
- 建议面板在页面底部，需要大量滚动才能看到
- 信息层次混乱，输入区和结果区边界模糊
- "计算"需要手动点击按钮

### 方案
- **建议卡上移**：结果面板紧跟在输入区下方，无需滚动即可看到
- **自动计算**：输入变化后 500ms 防抖自动触发计算，移除手动"计算"按钮
- **顶栏精简**：仅保留当前街道标签、筹码显示、设置入口

---

## 二、快速输入系统

### 2.1 选牌：全屏弹窗 → 底部抽屉

**现状问题**：选牌弹窗遮住整个屏幕，失去牌桌上下文；4列×13行网格在手机上小且密。

**方案**：
- 底部抽屉（半屏），上方仍可见游戏状态
- 交互流程改为两步：**先选花色（4个大按钮）→ 再选点数（13个按钮）**
- 已使用的牌灰显禁用，逻辑不变
- 点击抽屉外部关闭，不变

**实现要点**：
- 用固定定位 `position: fixed; bottom: 0` 的 div 替代现有 `fixed inset-0` 弹窗
- 花色选中状态只展示对应列的点数
- 动画：`translate-y-full → translate-y-0`，200ms ease-out

### 2.2 Hero 下注：手动输入 → 快捷按钮 + 自定义

**现状问题**：只有一个文本框，每次下注都要手动计算并输入金额。

**方案**：在现有输入框上方新增一排快捷按钮：

| 按钮 | 计算逻辑 |
|------|---------|
| 1/3 池 | `Math.round(totalPot / 3)` |
| 1/2 池 | `Math.round(totalPot / 2)` |
| 底池 | `totalPot` |
| All-In | `heroStack` |

- 点击任意快捷按钮自动填入 `heroBet`，触发重新计算
- 保留文本框用于自定义金额
- 超出筹码时自动修正为 All-In（现有逻辑不变）

### 2.3 对手操作：逐个手动输入 → 行内快捷操作

**现状问题**：每个对手都需要手动输入下注金额，弃牌需要点击状态切换按钮，流程分散。

**方案**：每个对手一行，三个内联操作：

```
[对手N]  [弃牌]  [跟注 $X]  [加注: ___]
```

- **弃牌**：点击后该行变灰，筹码计入底池（现有逻辑）
- **跟注**：自动填入当前最大下注额，点击即完成
- **加注**：小输入框，仅在需要时才输入数字
- 跟注金额实时跟随当前 `maxBet` 计算

## 三、建议面板重设计

### 问题
- 建议动作（Raise/Fold/Call）仅为文字，无视觉权重
- 理由使用 `font-mono` + 原始换行，包含 GTO/Equity/Pot Odds 等术语
- 三个下注选项外观相同，推荐项不突出
- 胜率仅显示数字，无直觉感

### 方案

#### 3.1 交通灯颜色系统

| 决策 | 颜色 | 背景 |
|------|------|------|
| 加注 / 下注 | 绿色 `#10b981` | `bg-emerald-900` |
| 跟注 / 过牌 | 黄色 `#f59e0b` | `bg-amber-900` |
| 弃牌 | 红色 `#ef4444` | `bg-red-900` |

整个建议卡的背景色和边框跟随决策颜色变化。

#### 3.2 白话理由

现有 `reasonKey` 对应的文案替换为面向新手的中文白话，不出现以下术语（仅在折叠详情中保留）：
- Equity → 用"胜率"
- Pot Odds → 用"对手跟注是否划算"描述
- GTO → 不出现
- SPR → 不出现（或在 ❓ tooltip 里解释）
- Outs → 在折叠区保留

新增白话 reason 字段到 `PokerData.js` 的 `TEXTS` 对象，与现有 reasonKey 并列。

#### 3.3 推荐金额高亮

三个下注按钮（小注/标准/大注）中，中间"标准"选项：
- 字体更大
- 带"★ 推荐"标签
- 边框更粗

#### 3.4 胜率可视化

在胜率数字上方新增进度条：

```jsx
<div className="w-full bg-slate-800 rounded-full h-2">
  <div className="bg-emerald-500 h-2 rounded-full" style={{ width: `${equity}%` }} />
</div>
<div className="flex justify-between text-xs text-slate-500">
  <span>0%</span>
  <span>需要 {potOdds.toFixed(0)}% 才值得跟注</span>
  <span>100%</span>
</div>
```

#### 3.5 进阶详情折叠

将以下信息收入可展开折叠区，默认折叠：
- GTO 胜率要求（Pot Odds）
- 牌型/牌面 key 原始值
- Outs 数量
- 位置建议原文
- 胜率趋势图（`EquityTrendChart`）
- 听牌概率图（`DrawProbabilityChart`）

折叠组件：点击"📊 查看分析详情 ▼"展开。

## 四、实现优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 建议面板颜色 + 白话理由 | 改动最小，收益最大 |
| P0 | Hero 下注快捷按钮 | 一排按钮，改动少 |
| P1 | 对手行内操作 | 重构对手列表渲染 |
| P1 | 进阶详情折叠 | 将现有内容收纳 |
| P2 | 选牌底部抽屉 | 需要改造弹窗组件 |
| P2 | 自动计算（防抖） | 移除手动按钮 |
| P3 | 胜率进度条 | 视觉增强 |
